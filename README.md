# Smart Inventory & Stock Management Analytics

A portfolio project demonstrating Python data engineering, inventory analytics,
demand forecasting, and interactive business reporting for a fictional e-commerce
business.

> **Data notice:** All records generated by this project are synthetic and do not
> represent a real company, supplier, customer, or transaction.

## Project configuration

- 500 products
- 50 suppliers
- 5 warehouses
- 12,000 sales transactions
- 1,000 purchase orders
- 365 days of simulated sales history

## Technology

Python, Pandas, NumPy, Streamlit, Plotly, SQLite (planned), Scikit-learn,
OpenPyXL, ReportLab, and pytest.

## Quick start (Windows PowerShell)

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python -m src.data_generator
streamlit run app.py
```

## Generated datasets

The generator writes six CSV files to `data/raw/`:

| File | Description |
|---|---|
| products.csv | Product catalogue, pricing, category and supplier |
| suppliers.csv | Supplier profiles and lead times |
| warehouses.csv | Five warehouse locations and capacities |
| inventory.csv | Product stock by warehouse |
| sales.csv | Synthetic sales transactions |
| purchase_orders.csv | Purchase orders and delivery status |

## Regenerate data

```powershell
python -m src.data_generator --seed 42 --days 365
```

The fixed seed makes the random choices reproducible. Dates are relative to the
day the generator is run, so date fields naturally move when regenerated later.
